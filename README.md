## 📌 Description

### TD (Travaux Dirigés)
Les TDs **TD1**, **TD2** et **TD3** contiennent des solutions sous forme de **photos** (images `.jpg`) représentant les résolutions manuscrites ou numérisées des exercices.

### TP (Travaux Pratiques)
Les TPs sont implémentés en **Python** :
- **tp1_tma.py** — TP 1
- **tp2_tma.py** — TP 2
- **tp3_tma.py** — TP 3

### Mini-Projet
Le mini-projet est divisé en deux parties :
- **Blind Source Separation** : implémentation de l'algorithme **FastICA** pour la séparation aveugle de sources audio, avec visualisation et calcul du SNR.
- **Partie 1** : code structuré en cellules (style notebook) dans des fichiers `.txt`.
